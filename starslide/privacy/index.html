Angbuilgu(이하 “발행자”)는 Starslide(이하 “앱”)를 제공합니다. 이 방침은 앱, 지원 문의 및 이 안내 웹사이트에서 정보를 처리하는 방법을 설명합니다. 개인정보 문의: sksmsdlscks@gmail.com

1. 게임 데이터와 기기 내 저장

앱은 계정이나 로그인을 요구하지 않습니다. 진행도, 별, 힌트 잔액, 사운드·햅틱 설정, 광고 노출 횟수 및 게임 진단 요약은 기기에 저장됩니다. 발행자는 이를 자동으로 수신하거나 자체 게임 서버에 저장하지 않습니다. 진단 요약은 사용자가 직접 복사하여 지원 문의에 첨부할 수 있습니다.

앱 데이터는 삭제할 때까지 기기에 유지됩니다. Android 설정에서 앱 저장공간을 삭제하거나 앱을 제거하여 로컬 데이터를 삭제할 수 있습니다. 기기·운영체제의 백업 설정에 따라 앱 데이터가 백업되거나 복원될 수 있습니다. 백업은 발행자의 서버가 아닌 해당 백업 서비스에서 관리하며, 삭제와 복원은 그 서비스의 설정을 확인해 주세요.

2. 광고와 Google 서비스

만 18세 이상이라고 응답한 이용자에게는 Google Mobile Ads를 통해 선택형 보상형 광고와 클리어 사이 전면 광고를 제공할 수 있습니다. 배너 광고는 없으며, 광고 시청은 게임 진행이나 섹터 해금의 필수 조건이 아닙니다.

광고 서비스는 광고 제공, 분석 및 부정행위 방지를 위해 IP 주소와 그로부터 추정한 대략적 위치, 앱·광고 상호작용, 성능 진단, Android 광고 ID·App Set ID 등의 식별자를 수집·공유할 수 있습니다. 광고 데이터의 보관 및 삭제는 Google의 정책과 이용자의 설정에 따릅니다.

3. 광고 동의와 선택

광고를 제공할 수 있는 이용자에게 필요한 지역에서는 Google User Messaging Platform(UMP)이 동의 선택을 제공합니다. 해당되는 경우 앱 설정의 “개인정보 선택”에서 선택을 변경할 수 있습니다. Android 설정에서 광고 ID를 재설정하거나 삭제할 수도 있습니다.

4. 어린이와 나이 확인

앱은 어린이와 성인 모두를 대상으로 합니다. 앱을 새로 실행할 때 현재 이용자의 만 나이를 확인하며, 응답하지 않고 계속할 수 있습니다. 입력한 나이는 저장하거나 전송하지 않으며, 광고 제공 여부 구분도 현재 실행 중에만 유지합니다.

만 18세 미만 또는 미응답 이용자에게는 광고를 제공하지 않습니다. 이 경로에서는 앱이 광고 SDK 초기화나 광고 동의 요청을 호출하지 않으며, 힌트는 광고 시청이나 잔액 소모 없이 사용할 수 있습니다. 18세는 앱의 보수적인 광고 제공 기준으로, 게임의 콘텐츠 이용등급을 뜻하지 않습니다.

다른 사람이 같은 기기로 플레이할 때는 앱을 완전히 종료한 뒤 다시 실행해 주세요. 보호자는 어린이의 개인정보와 관련한 문의 및 삭제 요청을 지원 이메일로 보낼 수 있습니다.

5. 지원 문의와 삭제 요청

이메일을 보내면 발행자는 발신 이메일 주소, 메시지와 첨부한 진단·스크린샷을 문의 답변과 문제 해결에 사용합니다. 이메일은 Google의 Gmail 서비스를 통해 처리됩니다. 문의 정보는 처리에 필요한 기간 동안 보관하고, 처리 종료 후 불필요한 정보는 삭제합니다. 법령상 필요한 경우 해당 기간 동안 보관할 수 있습니다.

발행자가 보유한 문의 정보의 열람·정정·삭제 등 개인정보 권리에 관한 요청은 지원 이메일로 보내 주세요. 로컬 게임 데이터와 백업은 1항의 방법으로 관리할 수 있으며, Google이 처리하는 광고 데이터는 2항의 링크 및 해당 서비스의 개인정보 설정에서 관리할 수 있습니다. 불필요한 신분증이나 민감한 정보는 보내지 마세요.

6. 정보 보호와 서비스 제공자

발행자는 지원 정보의 접근을 문의 처리에 필요한 범위로 제한합니다. 공개 웹사이트는 HTTPS를 사용하며, Google은 광고 SDK 데이터 전송에 TLS 암호화를 사용한다고 밝히고 있습니다. 어떠한 전송·보관 방식도 절대적인 안전을 보장하지는 않습니다.

Google(광고·동의·이메일)과 GitHub(웹 호스팅)는 각 서비스 제공에 필요한 정보를 해당 정책에 따라 처리하며, 이용자 국가 외의 서버에서 처리할 수 있습니다.

7. 안내 웹사이트

이 웹사이트에는 발행자가 설치한 광고·분석 스크립트나 추적 쿠키가 없습니다. 호스팅 제공자인 GitHub Pages는 보안을 위해 방문자의 IP 주소를 기록·보관합니다. 자세한 내용은 GitHub 개인정보처리방침을 확인해 주세요.
