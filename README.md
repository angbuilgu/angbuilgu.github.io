# Angbuilgu public website

Static Starslide support and privacy pages. This repository contains only public website files, not game source, signing material, or builds.

- Website: https://angbuilgu.github.io/
- Korean privacy policy: https://angbuilgu.github.io/starslide/privacy/
- English privacy policy: https://angbuilgu.github.io/starslide/privacy/en/
- Authorized ad sellers: https://angbuilgu.github.io/app-ads.txt

GitHub Pages publishes the root of `main`. No build dependencies, scripts, remote fonts, or analytics are needed. Keep both policy translations consistent when app behavior changes.

The app-ads.txt entry identifies the publisher's direct Google relationship. Serving the file does not itself mean AdMob verification is complete: the website must also be listed in the store and crawled by AdMob.
